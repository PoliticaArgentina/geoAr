# Un archivo de datos que contiene el listado de las geometrías para los censos disponibles

Un archivo de datos que contiene el listado de las geometrías para los
censos disponibles

## Usage

``` r
censos
```

## Format

Un tibble con 10 filas filas y 1 variables (censo)que funciona como id
para usar con
[`get_geo`](https://politicaargentina.github.io/geoAr/reference/get_geo.md)

- censo:

  ID correspondiente al año del censo de Argentina para descargar
  poligonos disponibles (1869 - 2010)
